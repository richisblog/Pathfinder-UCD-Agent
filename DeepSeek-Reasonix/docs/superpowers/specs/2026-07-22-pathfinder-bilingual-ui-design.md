# Pathfinder 双语界面与课程配对浮层设计

## 目标

修复 UC Davis 课程配对弹窗被左侧栏裁切的问题，并为中文、英文用户提供一个位于侧栏右下区域的一键语言切换入口。语言选择同时控制桌面界面和 Agent 后续回复语言。

## 交互设计

- 在工作台侧栏底部工具栏的设置按钮旁增加语言按钮。
- 当前界面为简体中文时，按钮显示“中”；当前界面为英文时，按钮显示“EN”。
- 点击按钮直接在 `zh` 与 `en` 之间切换，不打开菜单。
- 设置页原有语言选项继续保留，并与快捷按钮读取、写入同一语言偏好。
- 切换立即重绘当前页面，并持久化到桌面配置；重新启动后保持选择。
- 已经生成的历史聊天内容保持原文。切换后发起的新一轮对话，Agent 的可见思考与最终回复使用所选语言；代码、路径、命令和专有名词保持必要的原始形式。

## 语言数据流

快捷按钮调用现有 `LocaleProvider.setPref` 完成立即的 React 界面切换，同时调用后端 `SetDesktopLanguage`。后端继续作为持久化和 Agent 回复语言的唯一事实来源：它更新 `[desktop].language` 与用户级响应语言，并把新的响应语言应用到已经存在的实时控制器。

快捷按钮只提供 `zh` 和 `en` 两个目标。操作系统自动检测和已有其他兼容语言设置仍可在设置页中保留；若当前解析语言不是简体中文，快捷按钮第一次点击切换到简体中文。

## 国际化覆盖

- Pathfinder 新增的学生记忆、课程连接、待办栏和侧栏工具文案必须来自翻译字典。
- 本次触达的聊天输入区中仍然硬编码的用户可见中文文案必须迁移到翻译字典。
- 搜索关键词、代码注释、协议字段和平台缩写不属于用户可见翻译内容。
- 中英文翻译字典保持相同键集合；缺失键仍按现有机制回退英文。
- 根文档 `lang` 属性分别使用 `zh-CN` 和 `en`。

## UC Davis 配对浮层

根因是 `.sidebar` 使用 `overflow: hidden`，而当前 340px 绝对定位浮层会越过侧栏边界。浮层应脱离侧栏裁切上下文，锚定在课程连接按钮附近并渲染到页面级容器。

浮层必须满足：

- 完整显示标题、说明、配对码和所有操作按钮。
- 优先从课程连接按钮上方向右展开。
- 根据窗口边界自动调整横向位置；窄窗口中限制最大宽度并允许操作按钮换行。
- 侧栏收起和展开状态均可用。
- 点击课程连接摘要仍使用原来的 `details` 语义或等价的可访问按钮状态；关闭后不留下页面级浮层。

## 错误处理

- 前端立即切换界面；若后端保存失败，沿用现有设置错误通知机制并恢复或重新加载后端语言偏好，避免显示状态与持久化状态长期不一致。
- 配对状态查询、配对码申请和个人课表授权错误继续显示在浮层内。
- Agent 正在生成回复时不重写已经流式输出的文本；新语言从下一轮请求开始生效。

## 测试与验收

- 单元测试验证 `zh ↔ en` 的快捷切换目标。
- 组件/契约测试验证按钮位于底部工具栏设置按钮旁，并调用界面状态更新与 `SetDesktopLanguage`。
- Go 测试验证语言设置持久化并更新实时控制器的响应语言提示。
- 翻译契约测试验证本次新增的中英文键完整且关键 Pathfinder 页面不再硬编码用户可见中文。
- 浮层布局测试验证使用页面级锚定层，不再依赖会被侧栏裁切的绝对定位。
- 完整前端测试、TypeScript 构建、Wails arm64 打包、签名验证和 DMG 校验全部通过。

## 非目标

- 不自动翻译历史聊天记录。
- 不翻译用户输入。
- 不增加语言选择菜单或更多快捷语言。
- 不重写现有国际化框架，也不改变 CLI 的独立语言交互。
