# Third-party components

The browser bundle includes Apache ECharts and its zrender rendering engine.

- Apache ECharts: Apache License 2.0. See `licenses/Apache-2.0.txt` and `licenses/ECharts-NOTICE.txt`.
- zrender: BSD 3-Clause license. See `licenses/zrender-LICENSE.txt`.

Harness UI primitives and React are supplied by the application's browser module table; they are not copied into the production plugin bundle.
