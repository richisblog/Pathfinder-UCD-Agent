# Pathfinder UCD v0.1.0

Production build for macOS on Apple Silicon (arm64), built from the current Pathfinder UCD source.

## Included

- Pathfinder desktop academic consultation agent and multilingual frontend.
- Progress-aware consultation planning, campus lookup tools, and schedule bridge support.
- Bundled course, professor/review, major, change-of-major, and academic-calendar databases, plus policy text references.
- Fix for Chinese drop-course intent phrased as “退掉这门课”.

## Privacy and configuration

No user/account databases, chat history, private provider configuration, or API credentials are bundled. Raw review JSON is removed; email addresses and local filesystem paths are redacted from bundled text fields. SQLite databases are vacuumed after sanitization. Public professor names and academic material remain intentionally included.

Users must configure their own model provider credentials. Bundled data is a local snapshot and may be out of date.

## Validation

Production frontend and Go compilation completed. Campus progress/native/governance tests, Pathfinder frontend tests, data-staging tests, database integrity checks, and strict ad-hoc signature verification passed. No live model-provider or fresh-machine interactive acceptance test was performed.

## Installation

Open the DMG and drag **Pathfinder UCD.app** to **Applications**. This package uses an ad-hoc signature and is not Apple-notarized; macOS may require approving it in **System Settings → Privacy & Security → Open Anyway**. Intel Macs and Windows are not supported by this release.
