# RMP Consulting App / Pathfinder UCD

UC Davis academic advising workspace containing the current source snapshots of:

- **DeepSeek-Reasonix/**: Pathfinder UCD desktop application and schedule bridge extension. See its README and LICENSE for setup and usage terms.
- **RMPdemo/**: Flask academic advising chat website. See its README, `.env.example`, and LICENSE.
- **srcparse/**: supporting course parsing and calendar tools.

## Configuration

Private configuration, credentials, runtime datasets, logs, local toolchains, dependencies, and generated applications are excluded. Configure provider keys and OAuth settings through environment variables. The auxiliary tools use `GOOGLE_MAPS_API_KEY`, `SMTP_SENDER_EMAIL`, `SMTP_PASSWORD`, and `SMTP_RECEIVER_EMAIL`.
